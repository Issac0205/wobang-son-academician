## 0. 摘要（给主理人的 8 行结论）

1. 现实中的"副研究员→研究员"与"副教授→教授"是**两条并行的职称序列**，游戏里把它们串成一条线性阶梯（SPEC 要求）属于合理简化，但**年限口径应统一为"任职满 5 年"**（[A] 福建标准、[A] 中科院金属所细则）。
2. 职称晋升的**硬门槛是"项目 + 论文"二选一/组合**，不是纯论文数：福建标准明确"教学科研型：主持 1 项国家级项目 **或** 3 篇核心期刊（含 2 篇权威）"，且需 A 类 1 项 + B 类 2 项组合 [A]。
3. 人才"帽子"有**明确年龄上限**：青年基金 C 类 男 35/女 40；B 类（原优青）男 38/女 40；A 类（原杰青）男 45/女 48；长江特聘 ≤45（自科）；万人计划领军人才 ≤45 [A]。**年龄是游戏里最天然的"倒计时压力"资源**。
4. 经费量级可以做得非常真实：面上 50 万/4 年、青年 C 类约 30 万、优青级 200 万、杰青级约 400 万、重点 225 万/5 年 [A]。
5. 院士**不接受个人申请**，只能由院士或科协所属学会推荐，**每两年一次**；65 周岁以上候选人需 2 名院士推荐 [A]。2025 年中科院当选 73 人，平均年龄 57.2 岁，最小 44 岁 [A]。
6. 同类游戏里**最值得借鉴的是《品质校园模拟器》(MIT)** 的数值引擎抽象（满意度加权平均 + 天赋值模型 + tick 事件冷却 + 树洞触发链）与**《PhD Simulator》(MIT)** 的 **YAML 事件驱动引擎**；两者许可证都是 MIT，可安全复用思路与少量代码。
7. **不要整包复用任何一个项目**：QualityCampus 是 Cocos Creator 工程（与 SPEC 的"零构建纯前端"技术约定冲突），PhD Simulator 是 TypeScript 构建工程且作者声明不再维护 [A]。
8. **结论：完全自研，选择性借鉴 MIT 项目的数据驱动分层与事件引擎设计，不复制美术/文案。** 详见第 4 节。

### 1.2 有硬性出处的各级任职条件

**（a）高校教师系列（省级最细化的公开文本）**

《福建省高等学校教师职称评价标准》（闽教师〔2023〕73号，省教育厅+人社厅联发）给出了目前网络上**最具体、最可引用的量化条款** [A]：

- 学历资历（第九条）：
  - 教授：具有大学本科以上学历或学士以上学位，**聘任副教授满 5 年**。
  - 副教授：**具有博士学位后，聘任讲师满 2 年**；或本科以上学历/学士以上学位，聘任讲师满 5 年。
  - 讲师：具有博士学位；或硕士学位后任助教满 2 年；或本科任助教满 4 年。
- 教授业绩成果（第十六条，普通高校·教学科研型）：须同时具备 **A 类条件 1 项 + B 类条件 2 项**（不同条目），或 **A 类条件 2 项**。
  - A 类 1：**教学科研型发表 3 篇核心期刊论文，其中 2 篇权威期刊论文**（教学为主型为 2 篇核心、含 1 篇权威）。
  - A 类 2：**教学科研型主持 1 项国家级项目**，或 2 项省级以上项目（其中 1 项为部级项目或省级重点以上项目）。
  - A 类 3：获国家科学技术奖二等奖以上（排名前 8），或其他国家级教学/科研成果奖二等奖以上（前 3），或省级二等奖以上（第 1）。
  - B 类（节选）：主持 1 项省级以上项目；正式出版高水平学术著作（本人撰写 10 万字以上）或参编国家级规划教材（5 万字以上）；获 2 件国家授权发明专利；**科技成果转化实绩突出（横向项目取得重大经济/社会效益）**；2 项智库成果被国家部委或省委省政府采纳；指导学生获省级以上优秀学位论文等。
- 破格：破格晋升者**有效评审年度内年度考核须有 1 次优秀**（第十一条）。
- 岗位结构比例（现实中的"内卷"来源）：专业技术二至七级岗位不超过专业技术岗位的 **50%**，二至四级（正高）不超过 **20%**；二级岗位不超过二至四级的 20%，三级不超过 40%（中科院金属所细则第十八条）[A]。
- 来源：<https://jyt.fujian.gov.cn/xxgk/zywj/202401/t20240126_6387314.htm>

**（b）自然科学研究系列（中科院系统）**

《中国科学院金属研究所岗位管理实施细则》（科金人字〔2017〕11号，依据《中国科学院岗位管理实施办法》科发人字〔2017〕8号）[A]：

- 自然科学研究系列岗位设 12 个等级，其中**研究员 4 级、副研究员 3 级、助理研究员 3 级、研究实习员 2 级**。
- 第二十三条：**研究员四级岗位，须任副研究员岗位满 5 年**；研究员三级须任研究员满 3 年；研究员二级须任研究员满 6 年（研究员一级按国家规定）。
- 来源：<http://www.imr.cas.cn/xwzx/tzgg/202011/P020251226728070099655.pdf>

**（c）制度改革方向（"破五唯"，可用于游戏的"诚信值/代表性成果"系统）**

人社部、教育部《关于深化高等学校教师职称制度改革的指导意见》（人社部发〔2020〕100号）[A]：
- 高校教师职称层级：助教（初级）—讲师（中级）—副教授（副高）—教授（正高）；鼓励探索"助理教授"等职务聘任改革。

- **代表性成果制度**：可将理论文章、智库成果、技术方案、专利、成果转化、著作、教材、案例等作为代表性成果（福建标准第六条亦有同款表述）。
- 来源：<http://www.moe.gov.cn/jyb_xxgk/moe_1777/moe_1779/202101/t20210126_511116.html>

### 1.4 院士（阶梯终点）

《中国科学院院士增选工作实施办法（试行）》（2025 年 4 月发布）[A]：

- **每两年增选一次**（第四条）；名额、领域、资格条件由学部主席团在每次增选前制定增选指南并**向社会公开发布**。
- 候选人由**院士**或**中国科学技术协会**组织全国性学术团体**推荐**，**不受理个人申请**（第六条）。
- 有效推荐门槛：候选人获 **1 名院士**推荐且专业学部相同/相近即有效；**年满 65 周岁的候选人需 2 名院士推荐**（第九条）。
- 中国科协渠道：被推荐人**年龄不超过 65 周岁**（第十条）。
- 取消资格情形：**已连续 3 次被推荐为有效候选人**的，停止 1 次候选人资格（第十二条）。
- 导向："坚决破除'四唯'，打破论资排辈，**不以'帽子'进行评判**"，名额向国家急需关键领域、基础学科、新兴交叉学科倾斜（第五条）。
- 来源：<https://yszx.casad.cas.cn/bfgd/202504/t20250418_5064696.html>

- 新当选中科院院士：数学物理学部 14、化学部 11、生命科学和医学学部 13、地学部 9、信息技术科学部 11、技术科学部 15。
- **平均年龄 57.2 岁，最小 44 岁，最大 66 岁，60 岁（含）以下占 67.1%**；女性 5 人。增选后中科院院士总数 **908 位**。
- 来源：<https://www.edu.cn/ke_yan_yu_fa_zhan/gao_xiao_cheng_guo/gao_xiao_zi_xun/202511/t20251121_2702137.shtml>

### 1.5 论文 / 分区 / 影响因子：哪些能引用，哪些只能"估算"

| 概念 | 可引用的客观事实 | 数值量级 |

| 影响因子 IF | Clarivate JCR 每年发布；学科差异极大（数学顶刊 IF<5，生物医学顶刊 IF>30） | — |
| "一区 IF 量级" | **无官方硬线** [C] | 生物医学/材料：一区多为 IF ≥ 8–10；化学/工程：一区常见 6–10；二区 4–8；三区 2–5；四区 <2；数学/人文：一区 IF 常在 2–4。**推断依据**：中科院分区按学科前 5%（1 区）划分，因此 IF 阈值随学科浮动，不存在全局硬线。<https://www.fenqubiao.com/> （分区表官网，查询需机构账号）|
| 高校招聘/晋升中的"数量线" | 各校自定，公开文本极少；福建标准是少数给出确切篇数的省级文件 [A] | 教授：3 篇核心（含 2 权威）或 1 项国家级项目 |

### 2.2 国家重点研发计划 [A]

- 管理依据：《国家重点研发计划管理暂行办法》（国科发资〔2024〕28号，科技部+财政部，2024-03-31 成文）[A]。
- 层级：**重点专项 → 项目 → 课题**；专项是组织实施载体，项目是基本单元。
- 组织模式：竞争择优、定向委托、分阶段滚动支持；含"揭榜挂帅"、"赛马制"、**青年科学家项目**、长周期项目等。
- **项目（课题）负责人原则上不超过 60 周岁**（第十四条）[A]。
- **青年科学家项目不下设课题、原则上不再组织预算评估**，鼓励青年科学家探索颠覆性路径 [A]。
- 限项参考：中央财政专项资金预算**不超过 400 万元**的"政府间国际科技创新合作"等项目与国自然部分项目联合查重规则 [A]——可作为"国家级大项目"的金额锚点。
- 来源：<https://www.most.gov.cn/xxgk/xinxifenlei/fdzdgknr/fgzc/gfxwj/gfxwj2024/202404/t20240422_190406.html>
- 专项指南执行口径（中国科大转发）：<https://www.ustc.edu.cn/info/1362/21937.htm>
- 量级结论：**国家重点研发计划单个项目通常在千万级（数百万～数千万元），单个课题在数百万级** [C]。推断依据：项目由多课题组成、中央财政专项资金单项可达数百万元以上、且需跨单位团队承接。

### 3.1 《品质校园模拟器》hehao98/QualityCampusTheGame ⭐ 最值得借鉴

- 仓库：<https://github.com/hehao98/QualityCampusTheGame>；GDD：<https://cdn.jsdelivr.net/gh/hehao98/QualityCampusTheGame@master/GameDesignDocument.md>（GitHub 需代理，可用 jsDelivr 镜像读取）
- 题材：经营一所中国大学，从"二本→一本→211→985"的阶段目标推进，最终建成世界一流大学。标签：策略、模拟、文字、**荒诞、黑色幽默** —— 与本项目调性完全一致。
- 技术：**Cocos Creator 2.1.3**（Cocos2D/WebGL）、JavaScript、npm + ESLint + mocha；3 人 11 周 4 轮迭代；面向桌面网页/移动网页/微信小程序。
- **许可证：MIT**（Copyright (c) 2019 Hao He, Pai Tong, Mingyang Liao）；package.json 中 `"license": "MIT License"`。← 可合法复用代码与素材，只需保留版权声明。
- 可借鉴机制（全部为纯数值逻辑，与引擎无关，可 1:1 移植思路）：
  1. **五大指标分层**：学业水平/职业能力/科研水平/生活质量满意度 + 下级满意度子项（清洁、休息、学习环境…）。
  2. **满意度更新公式**：新值 = 历史满意度 × 0.95 + 当前环境影响 × 0.05（加权平均，平滑不跳变）；影响值再乘"拥挤度修正系数"（当前人数/容量，>1 时压到 1）。
  3. **天赋值模型**：每个学生有固定天赋上限；满意度只能让学生"接近天赋"，不能超过 → 想要更高产出**必须招更好的学生**。新生学业值 = 天赋 × 0.45。
  4. **招生反函数**：欲维持天赋 x 的新生入学，需满意度 ≈ 3x/4 + 1/4；开局无学生时新生天赋取 0.28（约需 0.46 满意度维持）→ 直接给出了"数值自我平衡"的数学形式。
  5. **事件系统**：每 tick 遍历事件，满足条件即触发；一次性事件永久关闭，其余触发后进入随机冷却 → **冷却驱动的随机事件池**，正是本项目"随机事件/坏结局"需要的骨架。
  6. **树洞系统**：对每种满意度维度设计"触发链"，链内按条件随机发一条学生内心独白，然后整条链进入随机冷却 → **把数值变成可读的学生情绪文本**，极适合做"与学生交流/幸福度"的叙事反馈。
  7. **教授（导师）系统**：三维能力（学术教学/科研/职业教育）+ 数量管理；实际影响 = 团队均值 × 师生比；操作仅有"招募/砸钱提升" → 本项目"设备加成/学生能力"完全可套用"均值 × 比例"的结构。
  8. **交互约束**：只用"点击 + 拖动"，避免悬停浮窗与键盘快捷键，字体足够大；桌面与移动端同构。
- 不建议照搬：Cocos 工程结构（与 SPEC"零构建、ES Module + 单文件 HTML"冲突）、其美术来自实景照片（版权风险）、"实时 tick"节奏（本项目是月度回合）。

## 4. 明确结论：完全自研，选择性借鉴

**结论：本项目应当"完全自研"，不 fork 任何现有开源项目，但可以合法借鉴两个 MIT 项目的"设计"（不是代码资产）。**

理由：

1. **技术栈冲突**。SPEC 第 8 节（主理人约定）要求"纯前端、零构建依赖、ES Module + 单文件 HTML 发布、文件双击即玩"。QualityCampusTheGame 是 Cocos Creator 工程（必须用 Cocos 编辑器与构建链），phd-game 是 TypeScript + npm 构建（产出 dist 包）。引入任一者都要连带引入整套构建/编辑器依赖，**直接违背零构建约定**。
2. **复用成本高于自研成本**。本项目核心是数值与文案（经费、职称、幸福度、诚信值），逻辑量级约数千行；而"读懂并裁剪一个他人引擎"的边际成本并不低于按 SPEC 的 `src/core + src/data + src/ui` 结构从零写。
3. **许可证虽友好，但"资产"不可靠**。QualityCampus 的图片来自网络实景照片（GDD 自述），其再许可状态不明；kw66/PhD_Simulator 与 tenure-run **没有可用的开源许可证**，一旦复制代码/文案即构成侵权风险。
4. **可借鉴的是"设计范式"，而设计范式不受版权保护**，且上述范式已被本报告固化为数值规范（第 5 节），落入 `src/data/` 即可：
   - 采纳 phd-game 的**数据驱动事件引擎**（事件 = 条件 + 动作 + 效果，规则集放 YAML/JSON 数据表）；
   - 采纳 QualityCampus 的**满意度加权平滑 + 天赋上限模型 + 事件冷却池**；
   - 采纳 kw66 的**模块分层**（core / features / systems / ui / config）—— 与 SPEC 的目录约定一致；
   - 采纳 Tenure Run 的**零依赖单文件 HTML 交付**。
5. **差异化要保留**：同类作品都回避了"抢一作"（果壳文中玩家抱怨"导师竟然不会跟学生抢一作"），而 SPEC 明确要求"可以从学生那里抢夺一作""造假蒙混"—— 这是本项目最独特的卖点，**不应向任何现有项目的"善良"审美靠拢**。

**执行建议**：docs/CREDITS.md 中记录"设计参考了 MIT 许可的 QualityCampusTheGame 与 PhD Simulator 的公开设计文档/代码结构，未复制其代码与素材"；不引入任何第三方运行时依赖。

- 加一个"年龄越来越大"的隐藏计时器：**超过 60 岁后院士推荐难度指数上升**（现实：项目负责人原则不超 60 周岁 [A]，65 周岁候选人需 2 名院士推荐 [A]）。

### 5.4 诚信值与坏结局（本项目的差异化核心）

- 初始 100（SPEC）；建议各行为扣减：抢一作 **-8**（对应"大幅减少"）、造假蒙混被查 **-25**、"多人攻坚"挪占他人项目进度 **-3**、购买一作 **-4**（对应"减少比较少"）。
- 好消息：项目按期结题 **+2**、学生顺利毕业 **+3**（SPEC："完成项目可以提高"）。
- 诚信 0 → 举报坏结局（SPEC）；建议同时加"概率性曝光"：造假连续使用 3 次后每回合 15% 触发举报审查（现实对应：连续 3 次院士有效候选人即停 1 次资格 [A]，可写进文案彩蛋）。

### 5.5 幽默化与叙事建议（依据调研得出）

1. **把"四唯"和"破四唯"同时写进台词**：文件明确"坚决破除四唯"[A]，而游戏机制偏偏只看 IF —— 这种反差本身就是最好的黑色幽默。
2. **引用真实制度做彩蛋**：院士"不受理个人申请"[A] → 玩家点"申请院士"按钮时提示"你无权申请，请先找到愿意推荐你的院士"。
3. **树洞/学生内心独白**（借鉴 QualityCampus 的树洞链）：把幸福度数值翻译成学生吐槽，解决"数值看不懂"的问题。
4. **《星礼研究所》的"血条=头发"**思路可移植为：导师的"健康值"用发量/黑眼圈图标表示（SPEC 已有健康值影响精力）。
5. **避免道德说教**：同类作品实测数据显示，玩家在拥有权力后大多选择"做好导师"（果壳采访原话），因此负面选项应"有利可图但代价明确"，而不是被系统惩罚性劝退。
