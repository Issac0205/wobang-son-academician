## 本版本的玩法变化（相对 0.1.0 骨架）

- **一作归属模型**：结题论文分「学生一作」与「玩家一作」两本账；只有玩家署名的一作能推晋升阶梯，学生一作只涨总 IF。这是把「把马小程送上院士」变成可玩策略的核心机制。
- **亲带 / 买 / 抢 三条来源**：亲带稳但牺牲项目速度；买贵且掉诚信；抢快但重罚（诚信 −8 + 该生幸福 −30 + 心结 6 个月）。
- **一作空窗提示**：连续 ≥24 个月没拿到自己的一作时顶栏提醒并给出三条途径与代价。
- **多项目幸福度惩罚**：让学生「挂着多个项目却不产出」不再是免费的。
- **延毕要签字**、**抢一作按篇二次确认**、**一键分配工作**（幂等、边界原因如实回显）、**无存档首屏项目市场修复**。
