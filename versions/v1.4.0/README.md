## 本版本的玩法变化（相对 1.3.0）

- **稀有人才彩蛋**：每年招生季里，8 位「十年一遇」的候选人各按 5% 独立出现；卡片挂「★ 稀有人才」+ 专属 flavor，招募走专属二次确认并写明「★ 本局只有这一次机会」。
- **120% 天赋**：入组后课题组卡片直接显示「科研能力 120%」（普通学生 ≤95%）；事件加减也按 rare 分支取上限，不会把 120% 悄悄降回 95%。
- **替位入场**：彩蛋候选人不会撑破学生席位，市场容量不变式一条不放宽（满员时挤走一位普通候选人）。
- **防同名**：这 8 个名字进 `NAME_BLOCKLIST`（随机拼名永不拼出他们），彩蛋只能由 `RARE_TALENTS` 独立注入。
